# 39: Produce an implementation-ready Shared Views spec

**What to build:** Produce an approved specification for explicitly sharing selected reports or records without converting personal ledgers into a household-wide shared ledger.

**Blocked by:** 35: Analyze pilot usage and select Phase 2 workstreams.

**Status:** ready-for-agent

- [ ] Discovery identifies the exact information users need to share and with whom.
- [ ] Sharing is scoped by owner, recipient, selected records/report, purpose and duration.
- [ ] Financial Contact connection alone grants no sharing access.
- [ ] Access expiry and immediate revocation behavior are specified.
- [ ] Revocation blocks future access without deleting the owner's source records.
- [ ] Sensitive links/tokens are owner/recipient-bound and non-guessable.
- [ ] Export, screenshot limitations and residual disclosure risks are explained honestly.
- [ ] Cross-user tests, audit requirements and incident handling are complete before implementation tickets.
