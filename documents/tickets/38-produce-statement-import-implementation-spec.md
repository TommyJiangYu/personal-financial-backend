# 38: Produce an implementation-ready Statement Import spec

**What to build:** Produce an approved specification for secure PDF/bank-statement import as a staged parse, deduplicate, preview and batch-confirm workflow.

**Blocked by:** 35: Analyze pilot usage and select Phase 2 workstreams.

**Status:** ready-for-agent

- [ ] Target statement formats and banks are selected from observed user demand.
- [ ] Upload size, MIME/content validation and malicious-document handling are specified.
- [ ] Raw statement privacy, provider processing and retention receive a dedicated assessment.
- [ ] Imported rows pass owner authorization, mandatory date, category and duplicate rules.
- [ ] Transfers, withdrawals, card payments and refunds are classified without inflating Income/Expense.
- [ ] Batch preview, correction, confirmation, cancellation and partial failure behavior are defined.
- [ ] Duplicate interaction with existing text/image Transactions is specified.
- [ ] The final spec contains external acceptance tests and receives product/privacy approval before implementation tickets.
